# WASSI DELIVERY

Application de gestion des livraisons de WASSI DELIVERY (Niamey) : closeuses, livreurs, responsable des opérations, CEO et e-commerçants.

- Application web installable (PWA), sans dépendance : `index.html`, `css/`, `js/`.
- Serveur : Google Apps Script relié à un Google Sheet (`google-apps-script/Code.gs`).
- L'adresse du serveur est dans `js/config.js`.

Les données de l'entreprise ne sont pas dans ce dépôt : elles restent dans le Google Sheet privé, derrière les comptes de l'application.
